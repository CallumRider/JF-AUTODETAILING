JFAUTODETAILING WEBSITE TEMPLATE
================================

OPEN THE WEBSITE
1. Open index.html in a browser.
2. Keep the folder structure unchanged so CSS and JavaScript continue to load.

WHAT IS INCLUDED
- 10 responsive HTML pages
- Shared modern orange / yellow, silver, black and charcoal design
- Mobile navigation
- Scroll animations
- Interactive before/after gallery slider
- Multi-step booking form demo
- FAQ accordions
- Placeholder image blocks and editable text

IMPORTANT BEFORE PUBLISHING
- Replace all [ ... HERE ] image blocks with real images or video.
- Replace every phone number, email, social link and opening hour.
- Replace placeholder prices, reviews, locations and vehicle counts.
- Confirm claims such as fully insured, DBS checked, eco-friendly and satisfaction guarantee.
- Connect forms to a real booking/form system.
- Add a real Google Map embed and social feeds.
- Add privacy, terms and cookie policy pages.
- Test accessibility, SEO and form handling before launch.

EDITING
- Main colours and layout: assets/css/style.css
- Interactions: assets/js/script.js
- Page content: edit the matching .html file

PROJECT RECORDS
- PROJECT-MASTER-CHECKLIST.md: complete status and task checklist
- PROJECT-FILE-INVENTORY.md: exact file inventory with sizes and hashes
- PROJECT-STATE.json: machine-readable project snapshot

QUICK EDITING
- Common phone, email, hours, location and social links: assets/js/site-config.js
- Main colours and layout: assets/css/style.css
- Logo expected by the site: assets/images/jf-logo.png
- Booking fields and steps: booking.html
